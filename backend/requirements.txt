# --- Quant alpha / risk / portfolio (qlib integration: api/quant/qlib_*) ---
# qlib has no wheel for Python 3.13, so build the bundled clone from source
# (requires an MSVC C++ toolchain for its Cython extensions). Install NON-editable
# so `import qlib` resolves from site-packages regardless of the launch directory —
# an EDITABLE install is shadowed by the ./qlib clone dir when the backend starts
# from the project root (as start_committee.bat does), breaking every qlib import:
#     .venv\Scripts\pip install ./qlib --no-build-isolation --no-deps
# IMPORTANT: run the backend with the venv's Python (.venv\Scripts\python), not a
# bare `python` that may resolve to a different interpreter without qlib installed.
# The following are qlib's lean-path RUNTIME deps we actually import (the heavy
# extras it declares -- jupyter/nbconvert/matplotlib -- are not needed):
